# ameei

| Folder | What it is |
|---|---|
| [`web/`](web) | The ameei storefront (Next.js + Prisma + Clerk + Stripe). Run commands from inside this folder. See [`web/SETUP.md`](web/SETUP.md). |
| [`design-system/`](design-system) | Brand tokens, logos, photography, voice, and AI-ad prompts. See [`design-system/README.md`](design-system/README.md). |

> Deploying on Vercel: set the project's **Root Directory** to `web`.
